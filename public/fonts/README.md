# Fonts

**Graphique** is a commercial typeface and isn’t bundled here.

### Use the real Graphique face
1. License Graphique (e.g. MyFonts / profonts)
2. Add the webfont file as:
   - `public/fonts/Graphique.woff2` (preferred)
3. Uncomment the `@font-face` block in `app/globals.css` (search for “Graphique”)

Until then, the intro uses **Bebas Neue** — a tall condensed Google Font in the same spirit.
